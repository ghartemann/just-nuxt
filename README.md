# Just-Nuxt

### It's just Nuxt 4. And some other stuff too.

This template was built with efficiency in mind, and is designed to be a lightweight and efficient starting point for Nuxt 4 projects.

You might want to check out the DockerFile and Docker Compose file as they're a bit specific to my configuration though.

### Contains

- Nuxt 4 (duh)
- Nuxt UI
- Nuxt Image
- Pinia
- VueUse
- ESLint
- Release-It
- Lucide Icons
- Nuxt anchorscroll
- some other things

make help
